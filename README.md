# Surecover

Placeholder site for **Surecover**, currently under development by **CHWEB**.

The homepage shows a minimal "under development" holding page: an animated
gradient infinity logo on an off-white background.

- **Framework:** [Next.js 16](https://nextjs.org) (App Router) + React 19 + TypeScript
- **Styling:** Tailwind CSS v4
- **Hosting:** [Vercel](https://vercel.com)

## Development

```bash
npm install
npm run dev
```

## Deploying to Vercel

Import the repository into Vercel (framework preset: **Next.js**) and deploy.
No environment variables are required for the current holding page.
